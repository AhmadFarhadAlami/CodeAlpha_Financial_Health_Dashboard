CodeAlpha Financial Health Dashboard

Project Overview

This project is a Financial Health Dashboard developed using Microsoft Power BI as part of the CodeAlpha Internship Program.
The dashboard provides an interactive view of financial performance, balance sheet position, cash flow activities, and revenue forecasting.

Objectives
- Analyze revenue, expenses, and net profit.
- Monitor monthly financial performance.
- Analyze assets, liabilities, and net worth.
- Track operating, investing, and financing cash flows.
- Forecast future revenue using historical trends.

Dashboard Pages

1. Financial Overview
- Total Revenue
- Total Expenses
- Net Profit
- Monthly financial performance analysis

2. Cash Flow Analysis
- Operating Cash Flow
- Investing Cash Flow
- Financing Cash Flow
- Monthly cash flow analysis

3. Balance Sheet & Forecast
- Monthly Balance Sheet Analysis
- Total Revenue
- Revenue Forecast
- Monthly filtering using a slicer

Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

Forecasting Method
A simple linear trend calculation using historical monthly revenue data to estimate revenue for the next three months.

Dataset
The project uses sample financial data for demonstration and analysis purposes.

Project Deliverable

Interactive Power BI report (.pbix).
